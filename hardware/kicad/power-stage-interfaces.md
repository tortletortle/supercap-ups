# 4S 电源候选电路接口

基线为 `4d1c83e`。KiCad 9.0.2 导出的基线网表有 17 条网络，ERC 为 0 错误、0 警告。下表包含现有网络及新增候选接口。

| 接口 | 方向或用途 | 连接约束 |
| --- | --- | --- |
| VIN_MAIN | 主电源输入 | 充电支路和主负载支路分别接入，确认掉电时各支路的反向电流 |
| PACK_4S | 超级电容组正端 | 充电输出、组端检测、放电断开器件的储能侧 |
| CELL_1–CELL_3 | 储能串抽头 | 从组端向地依次为 PACK_4S、CELL_3、CELL_2、CELL_1、GND |
| GND | 储能组负端和公共参考 | 大电流回流与电压采样连续性须在 PCB 设计中复核 |
| CHG_ALLOW | 从保护逻辑到充电使能的功能接口 | 默认停止充电，只有主源可用且所有单体电压允许时才充电 |
| CHG_OVP_OD | 单体过压联锁的低有效开漏输入 | 任一单体过压均可撤销充电。需把开路故障同时纳入 CHG_ALLOW 的默认禁充逻辑 |
| PACK_UV_OK | 组端欠压比较器许可 | 进入整机互锁，比较器输出负载、输出电平及恢复迟滞应与实际接收端一起核对 |
| DISCHARGE_ARM | 高有效硬件放电武装信号 | 当前图保留下拉和接口，系统许可发生器待完成 |
| VIN_BOOST | 储能支路断开器件之后的升压输入 | 经背靠背 MOSFET 与 PACK_4S 连接，关断漏电与导通压降另行验证 |
| BOOST_EN | TPS61088 使能 | 由互锁驱动，保留 TP2，核对关断后的漏电与输出状态 |
| BOOST_12V | 备用稳压输出 | 通过防反灌/切换电路连接负载，测量主电掉电和恢复波形 |

## 验收测点

- 充电测 VIN_MAIN、PACK_4S、四个单体差分电压和充电电流。覆盖空组上电、进入恒压、单体先触限、主源掉电、主源恢复和保护信号开路。
- 放电测 PACK_4S、VIN_BOOST、PACK_UV_OK、BOOST_EN、BOOST_12V 及负载端。覆盖带载掉电、欠压关断、恢复迟滞、阈值附近抖动和断开后的反向电流。
- 1.2 s 是仓库已有保持时间模型的目标。整机验收须同时记录 12 V 负载端电压、负载电流、初始组端电压、最低单体电压和主备切换压降。允许电压窗口与器件保护阈值待确认。

## 主备接管的候选时序

| 状态 | 储能侧 | 主备切换侧 |
| --- | --- | --- |
| 主输入建立，控制尚未稳定 | 充放电许可默认撤销。确认组端采样有效后才允许导通及升压 | 主电在其有效范围内供负载 |
| 主输入有效，储能可用 | 物理放电通路导通，Boost 预启动。先验证负载前的备源电压已进入规定窗口 | 保持主电优先，备源就绪才允许自动接管 |
| 主输入失效，备源已就绪 | 维持放电许可，硬件欠压仍可撤销许可 | 切换至备源，记录负载跌落和反向电流 |
| 主输入失效，备源未就绪 | 保持保护逻辑优先 | 切换器不得仅凭 Boost 的预偏置电压判定备源可用 |
| 放电欠压或单体欠压 | 撤销 Boost 使能并切断储能侧物理通路。备电时的组压回弹不得触发不停重启 | 主输入仍有效时保留主电，否则负载关断 |

以上为候选行为。许可保持及再武装电路需用独立台架验证，包括 MCU 未启动、主输入消失时控制供电仍有效，以及组端欠压后电压回弹。

## 充电许可验收

整合图的充电器使能与串联功率开关是两个独立关断点。CHG_ALLOW 控制 Buck，单体过压可通过 CHG_OVP_OD 拉低 Buck EN。串联开关 Q601 需要总压比较器许可及 CHG_SAFE_IN 同时有效。系统许可链完成前，CHG_SAFE_IN 保持低或高阻，5 V 电源建立本身不代表参考和采样链已经有效。

| 注入条件 | 捕获波形 | 整机目标 |
| --- | --- | --- |
| 主电上升或控制端复位 | VIN_MAIN、两路 5 V、两个基准、CHG_ALLOW、CHG_SAFE_IN、Q601 栅源电压 | 两路参考稳定且抽头状态确认后才允许充电 |
| 任一单体越过过压门槛 | 单体差分电压、CHG_OVP_OD、Buck EN、Q601 栅源电压、组端电流 | 禁充且串联开关断开。Q601 的单体联锁还待接线 |
| 总压超过保护门槛 | PACK_4S、OVP_OK、Q601 栅源电压、组端电流 | 即使 Buck EN 维持高，串联通路也应切断 |
| 主源断开且储能组已充电 | VIN_MAIN、两路 5 V、PACK_4S、反向电流 | 许可撤销，记录回灌与残余电荷。限能条件下验证端口反向偏置 |
| 过压解除或采样线重新接上 | 保护信号、复位信号、组端电流 | 按确定的复位流程重新使能，检查有无反复重启 |

台架应同时记录截止电流延迟和保护动作后的组端峰值。9.4 V 上限必须用实际波形验收。
